# VLM Evaluation Kit

Benchmarking framework for evaluating Vision-Language Models (GPT-4V, Qwen-VL, LLaVA, InternVL) on industrial inspection tasks including defect classification, localization, and quality grading.

Tested across textile, metal, glass, and PCB inspection domains.
